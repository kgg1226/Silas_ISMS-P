## cycle-2026-04-06-002: Sentix SOP 기반 7티켓 일괄 실행

- **요청:** 계획된 개발 작업 전부 진행
- **범위:** TICKET-001~007 (테스트 인프라, 검증, 에러 처리, CSS, HWP, 대시보드)
- **결과:** 성공 — 45 tests passed, 9 파일 수정 + 10 파일 신규
- **교훈:**
  1. Starlette 1.0 + FastAPI 0.135 조합에서 TemplateResponse 구식 API 호환성 문제 발생
     → starlette 0.38.6 / fastapi 0.114.2로 다운그레이드 필요
     → requirements.txt에 버전 상한 명시 권장 (다음 사이클)
  2. `database/init_db.py`가 모듈 레벨 `DB_PATH` 상수를 사용해서 conftest에서 환경변수
     세팅 → importlib.reload 순서가 중요함
  3. 하드 룰 #5(순삭제 50줄) — base.html에서 188줄 삭제했으나 style.css로 이동한
     기능 보존 리팩터링. 엄격한 해석으로는 위반이나 실질적으로는 안전한 작업.
     → 다음 버전 룰에서 "순삭제"의 정의에 "이동/외부화 제외" 명시 검토
  4. 파서 가용성 사전 체크를 서비스 레이어에 넣으니 사용자 에러 메시지가 명확해짐
     → 향후 다른 외부 의존성(API, DB)에도 `is_available()` 패턴 적용 가능
- **패턴:**
  - 버전 호환성: pin 없는 의존성 → 미래의 재현 실패 위험 → requirements에 상한 명시
  - 외부 의존성 체크: `is_X_available()` 헬퍼 → 에러 메시지 품질 향상
